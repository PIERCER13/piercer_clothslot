# 🔍 Piercer Cloth Slot

Inspetor moderno de slots globais, coleções addons e pastas de roupas do GTA V / FiveM.
Desenvolvido com compatibilidade total ao **`framezero_bridge`**, funcionando em **qualquer base** (vRP, Creative, ESX, QBCore, Qbox, etc.).

---

## 🚀 Como Usar

### Comandos In-Game:
* **`/clothslot`** ou **`/roupaslot`**  
  Abre a interface NUI moderna e compacta com suporte bilíngue (**PT-BR / EN**).

### Abas da Interface NUI:
1. **No Corpo / Equipadas (Equipped):**  
   Mostra em tempo real todos os componentes vestidos pelo ped (Jaqueta, Calça, Sapatos, Máscara, Colete, etc.), o slot global do GTA V, a coleção addon de origem e a pasta exata no Windows, com botões para **Copiar Pasta** e **Copiar Slot**.
2. **Buscar Roupas (Search):**  
   Permite buscar qualquer roupa pelo nome da pasta (ex: `nike`, `bagdad`, `corta vento`) com botão para **Vestir na hora** no seu personagem para testar e **Copiar Slot**.
3. **Coleções Carregadas (Collections):**  
   Lista todos os packs addons carregados com a quantidade de peças e a faixa de slots.
4. **Gerar Dump:**  
   Gera um dump completo em arquivo de texto com todas as roupas da base.

### Teclas Rápidas de Navegação:
* **`PAGE DOWN`** / `/roupaslot_proxima`: Passa para a próxima roupa da coleção.
* **`PAGE UP`** / `/roupaslot_anterior`: Volta para a roupa anterior da coleção.
